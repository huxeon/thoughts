# 我是怎么啃下 Attention Is All You Need 的

> 一篇写给自己的学习记录，也分享给想补基础却不知道从哪下手的同学。

## 起因：不想再看热闹了

前段时间 DeepSeek 发布 V4.1 Flash，据说架构上又有不少创新。DeepSeek 是我一直挺喜欢的公司，就点开了几篇解读——结果和以前一样，只看得懂热闹，看不懂门道。KV 缓存、解码器架构……这些词拆开每个都认识，连在一起就不知道在说什么。

按理说，我不该停在「看热闹」这一层。我本科读计算机软件与理论，现在研二，方向是智能媒体与数字工程。但所里做的大多是工程项目，对论文不太在意，我也就一直没认真读过模型相关的论文。时间久了，每次刷到新模型的文章，我都只能抓住最上层那点结论，再往下就露馅了。

这次不想再划过去了。我决定把《Attention Is All You Need》这篇经典论文真正啃下来。接下来的过程比想象中曲折，最后是靠着一份 Rust 代码，才把整个架构装进脑子。这篇笔记记录的就是这条路。

## 走过的弯路

刚开始我直接看原论文。英文水平有限，越看越乱，不知道这篇论文到底在讲什么。

后来想借 AI 一起学，效果也不好。某个概念不懂，问 AI 是能答上来的，但它答的都是孤立的点，串不起来。我还是觉得一头雾水。

于是我回去看 B 站飞天闪客的《一小时从函数到 Transformer》，他的内容挺适合没基础的人看。这次比上次有用——大概是因为带着问题去看，知道怎么抓大放小了。看完算是有了一点铺垫。

再回头找 AI，让它按论文的结构教我怎么学，效果好了些，但依然迷迷糊糊。来回徘徊了好一阵，直到某次聊天，AI 提议：可以写代码来展示 Transformer 的某个组件。我一想，这是好主意——读论文、啃数学推导我不在行，但代码我在行。

它先生成了一版 Python，很符合 AI 训练数据的分布，但我看着还是吃力。我平时主要写 C/C++ 和 Rust，Python 实在不算顺手，就让它换成 Rust。有点惊讶，AI 现在写 Rust 越来越好了。这一版，我终于能大致读懂了。

## 我理解的 Transformer

先说整体：模型吃进一个序列，经过词嵌入变成一组向量，再加上位置编码，送进若干层编码器和解码器，最后由解码器输出下一个词的概率分布。

Q、K、V 是对输入 X 的三次变换。我听人这么打比方：Q 是查询，K 是索引，V 是实际的内容。输入 X 是一个形状为 (n, d_model) 的矩阵，n 是序列长度，d_model 是每个词的向量维度。自注意力是对它做的一次变换，让每个向量都带上其他词的信息——至于为什么能带上，我还没想透。大致过程是：用 Q·Kᵀ 找出跟当前向量最相关的那些位置，再乘上 V 得到结果。这个式子的数学含义，说实话我不太懂，但知道它在干什么就够了。

位置编码：自注意力本身跟位置无关，为了让结果里体现出词的先后顺序，得额外把位置信息加进去。具体算法我没深究。

编码器和解码器：编码器负责「理解」，解码器负责「生成」、预测下一个词。不过「理解」到底是什么意思，我到现在也没想明白，就先按「把输入编码成某种表示」来理解。

## 真正帮上忙的是代码

看论文时，我最大的障碍是把握不住数据的流向：某个组件的输入是什么形状、输出是什么形状、内部变换的顺序是什么。字面描述绕来绕去，我脑子里始终拼不出一张完整的图。

那份 Rust 代码把所有组件都实现了——自注意力、前馈网络、位置编码、词嵌入、线性投影。顺着代码一路看下去，每个函数吃进去什么、吐出来什么，一清二楚。数据是怎么从头流到尾的，终于在我脑子里立起来了。

这中间我依然用自顶向下、抓大放小的方法：掩码算法、位置编码算法、层归一化算法，我都选择跳过，知道有这么个组件、知道它的功能就够了；多头注意力怎么算、前馈网络怎么算，这两块我多花了点力气。我知道自己的短板在数学——不是学不会，是太久没碰，很多概念生疏了。所以不跟推导较劲，知道它在做什么、做到什么程度，就收手。

## 还没想明白的问题

学完不等于全懂。不过也有一个疑问，是我后来绕清楚了的——开头提到的 KV 缓存。我之前一直以为「缓存」是跨层共用一份 K 和 V，可每一层的 K、V 明明不一样，怎么共用？后来才想明白：缓存不是跨层复用，而是每一层各自缓存自己的、在时间维度上复用。自回归生成时，已经生成的 token 在某一层的 K、V 不会因为后面新 token 加入而改变——因果掩码下，当前位置只看它前面的词。所以这层这一步算出来的 K、V，下一步还能直接用，只需要新算刚生成那个 token 的 K、V 再拼上去。每层存每层那一份，「每层 KV 不一样」和「能缓存」其实并不冲突。

至于下面这些，就是真正还没啃动的了：

- Q·Kᵀ 的数学含义：为什么这样一乘就能「找相关」。
- 位置编码的深层原理：为什么这样做就能让模型感知顺序。
- 编码器所说的「理解」，到底指什么。

## 结尾

回过头看，从「只会看热闹」到「能看懂一点门道」，中间差的不是智力，而是方法：自顶向下、抓大放小，再加上用自己熟悉的语言，把抽象的东西变得具体。现在再看 DeepSeek 那些文章，能抓住的东西确实比之前多了，虽然离「真正看懂」还有一段距离。

这篇笔记主要写给自己，也分享给可能和我一样、想补基础却不知道从哪下手的朋友。希望能对你有点用。
