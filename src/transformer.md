# Transformer

前段时间 DeepSeek 发布了新的模型 V4.1 Flash，据说模型效果挺不错，并且在架构上有很多创新。我之前很少去读模型相关的论文，对一些概念也知之甚少，比如 KV 缓存、解码器架构等等。想想其实不大好，每次看新模型相关的博客、文章啥的，都只能理解上层的东西。而 DeepSeek 是我比较喜欢的一家公司，就打算趁着这个机会学习下。原本是想就看这一篇文章，结果看的过程中磕磕绊绊，对很多概念不甚了解，模型架构也完全看不懂。之前也有在 B 站等平台看过 Transformer 的介绍，飞天闪客的内容是我比较喜欢的，很适合没有经验的人去看。但是这样学的总是不深刻，没有系统性的概念。所以就打算去学习一下那篇经典的论文——Attention is all you need.

刚开始的时候，我是直接去看的原始论文，但是限于我的英文水平，越看越感觉混乱，不知道在干什么。这个时候就打算借助 AI 来帮我一起学，可是没啥改善，某个概念不懂是可以问 AI，但是它不能把这些串起来，总是孤立的概念，还是让我觉得一头雾水。于是，我又去回顾了飞天闪客的视频——一小时从函数到 Transformer。只能说，比我上次看的有用，可能是因为了解的东西更多了，也可能是因为带着疑问去看的，知道怎么抓大放小。不管怎样吧，我最终把它看完了，算是作为一些知识铺垫。然后我又去找了 AI，让它根据论文结构来教我怎么学。效果变好了一点，但还是迷迷糊糊的，又来回徘徊了一段时间。不知是哪次聊天，AI 告诉我可以写代码来展示 Transformer 架构中的某个组件，我就想这是好事啊，虽然我对数学和论文不太懂，但是我懂代码哇。就让它继续生成了，生成的是 Python 代码，嗯，很符合 AI 训练的数据分布。我本以为自己能够看懂，结果却有点打击人，好吧，我承认我在 Python 上还是有所欠缺的。那怎么办呢，我熟悉 Rust 哇，就让 AI 生成了一版新的。有点小惊讶，AI 现在写 Rust 代码越来越好了。终于，我能够大致读懂了。在理解的过程中，我还是遵循了自顶向下、抓大放小的方法，先看了整体结构：输入、输出、编码器、解码器...。随后又了解了词嵌入、位置编码、Q、K、V 向量（矩阵？）、线性投影等等一系列部件。我知道我的劣势是数学，所以也没有过分纠结算法过程，知道它做了什么就够了。最后，借助了整个架构图，我逐渐理解了这篇论文在讲什么，并尝试将自己的理解和疑惑告诉 AI，让它判断我说的对不对。我终于算是弄清了这个架构。

当然，我学习这篇论文的主要目的就是补充一些基础知识，各种算法的优劣啊、模型架构的对比啊啥的就不在我的范围中了。是挺不错的一次阅读体验吧。
